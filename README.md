# Superstore Sales Analysis
Superstore Sales Analysis using Python, SQL , and Power BI to analyze sales, profitability, products, regions, and shipping performance.
## Project Overview
This project analyzes Superstore sales data to understand sales performance, profitability, product performance, regional trends, and shipping performance. Python, SQL , and Power BI were used to prepare, analyze, and visualize the data.
## Objective
- Analyze overall sales and profitability.
- Identify high-performing product categories and sub-categories.
- Analyze sales and profit across different regions and states.
- Evaluate product performance.
- Analyze shipping performance by shipping mode.
- Present key business metrics through an interactive Power BI Dashboard.
   ## Tools & Technologies
  - Python (Pandas, Numpy, Matplotlib, Seaborn)
  - Jupyter Notebook
  - SQL
  - Power BI
  - Github
 ## Data Preparation & Analysis
 The Superstore dataset was cleaned and prepared using Python in Jupyter Notebook. Data quality, columns, data types, and relevant sales and shipping fields were reviewed before analysis.
 Additional analysis was performed using SQL, and the cleaned data was used to develop the Power BI dashboard.
 ## SQL Analysis
 SQL was used to analyze sales, profit, products, regions, states, and shipping-related performance.
 ## Power BI Dashboard
 An interactive Power BI dashboard was created to provide an overview of Superstore sales and profitability .
The dashboard includes analysis of:
- Sales performance
- Profitability
- Product categories and sub-categories
- Customer segments
- Regional performance
- State-level profit
- Shipping performance
## Key Business Insights
- Sales and profitability vary across product categories and sub-categories.
- Regional and state-level analysis helps identify differences in sales and profit performance.
- Product-level analysis highlights high-performing products.
- Shipping modes can be compared based on average shipping days.
- The dashboard provides a consolidated view of sales, profit, product, regional, and shipping performance.
